# CS50 Python Exercises

This repository contains my solutions to programming exercises from the CS50 course offered by Harvard University. I am currently completing this course online through Fundação Estudar.

## About the Course

CS50 is an introductory course in computer science that covers fundamental topics such as algorithms, data structures, and software development. The course emphasizes problem-solving and includes practical assignments implemented in Python.

## Purpose

The purpose of this repository is to:

- Reinforce concepts learned throughout the course  
- Document my progress  
- Practice problem-solving using Python  
- Build a solid programming foundation  

## Exercises Included

### Mario (Less)
Prints a right-aligned half-pyramid using hashes (#), based on a user-defined height between 1 and 8.

### Mario (More)
Prints a double half-pyramid with a gap of two spaces between them.

## How to Run

Open the project in PyCharm and run the desired file using the built-in run option.

## Topics Covered

- Input validation  
- Control structures  
- Loops and iteration  
- String manipulation  
- Basic algorithmic logic
